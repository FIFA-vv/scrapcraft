# Scrapcraft

Welcome to Scrapcraft! This is a complete dynamic celebration webpage generator platform built as a local backend.

## Features
- Dynamic Customization Studio with Live Preview
- 9 Beautiful Pinterest-inspired background patterns
- Immersive Memory Timelines (Photos & YouTube/MP4 embeds)
- Auth locked admin & secure API architecture
- Automated deployment-ready `express` engine to spin `.zip` outputs securely.

To run:
```bash
npm install
npm start
```
